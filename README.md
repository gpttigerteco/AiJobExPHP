# AiJobExPHP

سیستم مدیریت شرح وظایف و چت سازمانی بر پایه PHP 8.2، MySQL 8 و Bootstrap 5 RTL.

## ویژگی‌ها

- معماری لایه‌ای سبک با Router ساده، Controller، Service و Repository.
- احراز هویت مبتنی بر سشن، RBAC و میان‌افزارهای CSRF.
- رابط کاربری واکنش‌گرا با Bootstrap 5.3 RTL و کامپوننت‌های مدرن.
- سرویس هوش مصنوعی با معماری RAG و امکان اتصال به ارائه‌دهندگان مختلف.
- ابزارهای پایه گزارش‌گیری و خروجی CSV.

## ساختار پوشه‌ها

```
public/           # Front controller و دارایی‌های استاتیک
app/              # کد اصلی برنامه (Controllers, Services, Repositories, Views, Core)
storage/          # لاگ‌ها و کش
config/           # تنظیمات برنامه و دیتابیس
```

## راه‌اندازی

1. نصب وابستگی‌ها:

   ```bash
   composer install
   ```

2. کپی فایل env:

   ```bash
   cp .env.example .env
   ```

3. تنظیم دسترسی پوشه آپلود و storage.
4. ساخت دیتابیس MySQL طبق اسکریپت `schema.sql` (در حال تهیه).
5. تنظیم وب‌سرور برای اشاره به `public/`.

## اسکریپت‌های کاربردی

- `composer dump-autoload` برای به‌روزرسانی autoload.
- اجرای تست‌ها (در آینده) با `vendor/bin/phpunit`.

## وضعیت فعلی

این ریپو حاوی اسکلت اولیه پروژه به‌همراه صفحات نمونه و سرویس‌های ماک است تا توسعه تیمی سریع‌تر آغاز شود.
